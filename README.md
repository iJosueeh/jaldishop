## Descripcion

Sistema web orientado a la **gestion de pedidos y control de capacidad** disenado para Micro y Pequenas Empresas (MYPE). La plataforma permite administrar el flujo de pedidos en tiempo real, optimizando recursos y mejorando la eficiencia operativa del negocio.
